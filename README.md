# TLP - Práctica SOLID

Refactorización de 5 ejercicios aplicando los principios SOLID en TypeScript.

- `01-srp.ts` — Single Responsibility Principle
- `02-ocp.ts` — Open/Closed Principle
- `03-lsp.ts` — Liskov Substitution Principle
- `04-isp.ts` — Interface Segregation Principle
- `05-dip.ts` — Dependency Inversion Principle

Cada archivo termina con un bloque de "Respuesta:" con las preguntas de la consigna.

## Cómo ejecutar

Requiere Node 22.6 o superior (ejecuta `.ts` directo).

```bash
npm install
npm run 01-srp   # y así hasta 05-dip
```
